# alwtasks — доска задач

Веб-приложение на Node.js, без внешних npm-пакетов. Задачи и история хранятся в SQLite.

## Запуск локально

Требуется Node.js 22 или новее.

```powershell
node server.js
```

Откройте `http://localhost:4173`. Локальный режим хранит базу в `data/tasks.sqlite`.

## Подготовка Bothost

Проект слушает `0.0.0.0` и использует `PORT`. Для постоянной базы укажите `BOTHOST=1`: SQLite будет записываться в `/app/data/tasks.sqlite`, который Bothost сохраняет между деплоями.

В настройках Bothost включите «Использовать собственный Dockerfile» и сделайте новый деплой. Dockerfile запускает веб-сервер напрямую из `/usr/src/app`, чтобы bind mount исходников Bothost в `/app` не затёр файлы запуска; база остаётся в постоянном `/app/data`.

В переменных окружения Bothost настройте:

- `BOTHOST=1`
- `APP_PASSWORD` — длинный пароль для доступа к доске в обычном браузере (логин `tasks`)
- `BOT_TOKEN` или `TELEGRAM_BOT_TOKEN` — токен бота из BotFather (Bothost обычно передаёт Telegram-токен как `BOT_TOKEN`)
- `OWNER_TELEGRAM_ID` — Telegram ID владельца, который может создавать и менять задачи
- `MANAGER_CHAT_ID` — Telegram ID руководителя: он сможет смотреть прогресс и получать уведомления
- `WEBAPP_URL` — HTTPS-адрес опубликованного приложения

Напишите боту `/start`, чтобы получить кнопку открытия Mini App, и `/id`, чтобы узнать свой числовой Telegram ID. Запишите ID владельца в `OWNER_TELEGRAM_ID`, ID руководителя — в `MANAGER_CHAT_ID`, затем перезапустите бота. Mini App проверяет подпись `Telegram.WebApp.initData` на сервере; неизвестные Telegram-аккаунты не получают доступ. Руководитель видит доску в режиме чтения.

Подключите домен Bothost к этому приложению, укажите порт, совпадающий с `PORT` (обычно 3000 или 8000; выбранное значение Bothost передаёт в переменной `PORT`), затем запустите Node.js-приложение командой `node server.js`. Health-check: `/health`.

Никогда не публикуйте `.env` с секретами в Git. Приложение намеренно требует `APP_PASSWORD`, когда `BOTHOST=1`, чтобы не открыть список задач посторонним.

## Доступ

API принимает сессии Mini App только после серверной проверки подписи Telegram. Владелец может менять задачи, руководитель — только просматривать. Обычный браузер может открыть доску по `APP_PASSWORD`.

## Функции рабочего ядра

- свойства задач: статус, приоритет, сроки, следующий шаг, блокер, ответственный, теги, напоминание и повтор;
- пошаговый чек-лист внутри каждой задачи: добавление, отметка выполнения, удаление и прогресс `готово / всего`;
- планирование задачи на дату и время или через зависимость от другой задачи;
- представления «Список», «Канбан» и «Календарь»;
- поиск по содержимому и тегам, история изменений и архив;
- комментарии к задаче для руководителя и владельца;
- уведомления руководителю при создании и изменении задачи, а также отдельные напоминания по срокам;
- Telegram-команды `/start`, `/id`, `/today` и кнопка открытия Mini App.
